Crust&Cream — เว็บไซต์ดีไซน์ใหม่
=================================

ไฟล์ในชุดนี้
- storefront-desktop.html : หน้าร้านสำหรับคอมพิวเตอร์
- storefront-mobile.html  : หน้าร้านสำหรับมือถือ
- admin-desktop.html      : ระบบจัดการร้านสำหรับคอมพิวเตอร์
- admin-mobile.html       : ระบบจัดการร้านสำหรับมือถือ
- app.js / styles.css     : ระบบทำงานและดีไซน์ที่ใช้ร่วมกัน
- assets/                 : รูปภาพทาร์ตที่เก็บไว้ในเว็บ
- supabase-setup.sql       : คำสั่งสร้างฐานข้อมูลและกำหนดสิทธิ์

สิ่งที่ออกแบบใหม่
- โทนครีม ชมพูกุหลาบ น้ำตาล ให้ความรู้สึกโฮมเมดพรีเมียม
- เมนูสินค้า 5 รายการ อิงจากข้อมูลเดิม พร้อมส่ง / Pre-order
- ตะกร้าสินค้าและแบบฟอร์มสั่งซื้อ
- หลังร้านจัดการออเดอร์ สินค้า ราคา สต็อก และข้อมูลหน้าแรก
- เข้าระบบแอดมินด้วยอีเมลและรหัสผ่านผ่าน Supabase Auth แทนรหัส 1234

ขั้นตอนเปิดใช้งานฐานข้อมูล
1. เข้า https://supabase.com/dashboard/project/bhtgrxqprhbcxoncqgad
2. เปิดเมนู SQL Editor > New query
3. เปิดไฟล์ supabase-setup.sql คัดลอกทั้งหมดไปวาง แล้วกด Run
4. ไปที่ Authentication > Users > Add user แล้วสร้างอีเมลและรหัสผ่านของผู้ดูแลร้าน
5. คัดลอก UUID ของผู้ใช้ที่สร้าง
6. กลับไป SQL Editor แล้วรันคำสั่งนี้ โดยแทน UUID จริง:
   insert into public.admin_users (user_id) values ('UUID-ของแอดมิน') on conflict do nothing;
7. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้ขึ้น Cloudflare Pages โดยให้ไฟล์ HTML, app.js, styles.css และโฟลเดอร์ assets อยู่ระดับเดียวกัน

ลิงก์หน้าร้าน
- คอมพิวเตอร์: /storefront-desktop.html
- มือถือ: /storefront-mobile.html
- หลังร้านคอมพิวเตอร์: /admin-desktop.html
- หลังร้านมือถือ: /admin-mobile.html

หมายเหตุสำคัญ
- URL และ Publishable key ของ Supabase ถูกใส่ไว้ใน app.js แล้ว เป็นคีย์สำหรับฝั่งหน้าเว็บ ไม่ใช่ service_role key
- ห้ามใส่ service_role key หรือรหัสผ่านฐานข้อมูลลงในไฟล์หน้าเว็บ
- ต้องรัน SQL และเพิ่ม UUID แอดมินก่อน จึงจะเข้าสู่ระบบหลังร้านและบันทึก/อ่านข้อมูลออนไลน์ได้
- ถ้ายังไม่ตั้งค่าฐานข้อมูล หน้าร้านจะแสดงสินค้าโหมดตัวอย่าง แต่จะไม่รับคำสั่งซื้อออนไลน์
- การเพิ่มรูปสินค้าในหลังร้านให้ใส่ URL หรือ path เช่น assets/tart-strawberry.webp (ระบบอัปโหลดรูปขึ้น Storage ยังไม่ได้รวมในชุดนี้)
- ฐานข้อมูลเริ่มต้นด้วยสินค้าตัวอย่างตามข้อมูลเดิม ราคา 185, 195, 175, 220 และ 190 บาท ปรับได้ในหลังร้าน
